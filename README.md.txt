# Student Portal Management System

## Project Description
The Student Portal Management System is a Flutter-based application integrated with Firebase Firestore for managing student information, attendance, grades, and reports.

## Features
- Student registration and management
- Attendance tracking
- Grade management
- Report generation
- Firebase Firestore integration
- Search functionality

## Technologies Used
- Flutter
- Dart
- Firebase Firestore
- Android Studio
- Git and GitHub

## Documentation
Project documentation is available in the `documentation` folder.

## Installation
1. Clone the repository.
2. Run `flutter pub get`.
3. Configure Firebase.
4. Run `flutter run`.
